# Model components

Start with `agent.py` for the GRU agent, `scene.py` for scene generation, and `label_mapping.py` for shared training/evaluation labels.

Other modules retain experimental architectures and earlier baselines. Their version identifiers refer to different configurations, not a single ordered performance comparison. See the [project overview](../../README.md) and [design notes](../../docs/design.md) for the selected research story.
